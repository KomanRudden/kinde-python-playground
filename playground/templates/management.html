Connect a machine-to-machine application

  1. In Kinde, go to Settings → Applications → Add application and choose Machine to machine.
  2. Under APIs, authorize it for the Kinde Management API and grant the scopes you need (e.g. read:users, read:organizations).
  3. Set KINDE_MANAGEMENT_CLIENT_ID and KINDE_MANAGEMENT_CLIENT_SECRET in .env and restart.

Use a separate M2M application rather than your web app's credentials, and never expose these calls to the browser.
